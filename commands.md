git init, Initializes a new local repository
git add . ,Stages all latest changes and prepares them to be commited
git commit -m, Saves your staged changes to the repository history
git status, Displays the state of your working directory
git log, Shows a chronological list of all the commits made in the repository
git checkout -b "branch name", create a new branch and go to that branch
git merge "branch name", merges the branch to the current branch
